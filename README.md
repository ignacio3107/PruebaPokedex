## 🧩 Arquitectura
### Se utiliza una arquitectura MVVM con Coordinator en todo el proyecto, ya que esta nos ayuda con:

- Escalabilidad del proyecto
- Separa responsabilidades
- Facilita las pruebas unitarias
- Facil de mantener
